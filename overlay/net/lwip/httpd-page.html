Restore entire Flash

Restores a main-area .bin from offset 0, including bootloader and board data. Chunks are written and verified before updating boot. Bad-block offsets stay in place; OOB is excluded. The file must match Flash capacity.

Clear bad block markers

Erases the entire NAND chip including factory bad blocks. All data will be lost.

Environment

Use httpd_ipaddr / httpd_netmask for the recovery address (next start). Set httpd_dhcp to 0 to disable DHCP persistently; 1 enables it on the next start.
